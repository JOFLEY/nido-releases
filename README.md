# Nido

Escritorio con carpetas expandibles para Windows 10 y 11.

## Instalar

1. Descarga **[Nido-win-Setup.exe](https://github.com/JOFLEY/nido-releases/releases/latest/download/Nido-win-Setup.exe)** (siempre la última versión).
2. Ábrelo. Se instala para tu usuario, sin pedir permisos de administrador, y Nido se abre solo.

Windows puede mostrar "Windows protegió su PC" porque el instalador no está firmado:
toca **Más información → Ejecutar de todas formas**.

## Actualizaciones

Nido busca versiones nuevas al iniciar y cada 6 horas. Cuando hay una, avisa en la bandeja del sistema:
un clic y se actualiza solo. También puedes buscar a mano desde el ícono de la bandeja → *Buscar actualizaciones*.

## Desinstalar

Configuración de Windows → Aplicaciones → Nido → Desinstalar. El escritorio de Windows vuelve a como estaba.
